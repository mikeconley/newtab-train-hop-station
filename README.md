# Newtab Train Hop Station

A tool for assessing the viability of a Firefox New Tab train-hop

Learn more about [Newtab train-hopping](https://firefox-source-docs.mozilla.org/browser/extensions/newtab/docs/v2-system-addon/train_hopping.html)

## Development

Requirements: The current [LTS](https://github.com/nodejs/LTS) (long term support) version of [NodeJS](https://nodejs.org/). This is necessary to run `web-ext`, a [command line tool](https://extensionworkshop.com/documentation/develop/getting-started-with-web-ext/) to run browser extensions locally.

Run the following commands:

1. Install node depenencies
```bash
    $ npm install
```

2. Run the extension locally. This will open a new browser with the extension installed.
```bash
    $ npm run dev
```
